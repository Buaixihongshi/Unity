Unity v1.0.0 正式版：把 Codex、Claude Code 和 Antigravity 放进同一个工作群，围绕共享对话、记忆与产物协作。

## 升级内容

相比 v0.2.0-preview.1：

- **文件与产物**：新增会话右侧产物栏和跨会话文件仓库，集中查看、下载生成的文件（#90）。
- **聊天体验**：独立的停止和消息编辑入口，回车换行；重启时收尾中断回合，减少会话锁死（#81、#85、#104）。
- **按需扩展**：讨论、任务和仓库维护默认关闭，可从设置启用；桌面版可在菜单中选择 Git 项目仓库（#53、#75、#77）。
- **观测与成本**：区分 Trace 可信度与 Agent 行为，失败按归属拆分；支持逐回合查看步骤、输出、检查项和成本（#109）。
- **设置排版**：自定义角色名称保持横排，统一连接控件高度；观测回合左右单元格与检查标签对齐（#113）。
- **Antigravity**：通过工作区插件挂载 MCP，支持不同会话的轮次并行（#118）。
- **视觉更新**：人物头像、莫比乌斯环启动与等待动效（#78、#116）。

## 下载与安装

- `Unity-1.0.0-arm64.dmg`：Apple Silicon（M 系列），macOS 12 或更高版本。
- 桌面包内置 Python 和前端产物，无需为应用另装 Python / Node；模型调用仍需安装、登录对应 CLI。
- 打开 DMG，将 Unity 拖入“应用程序”。本包使用 **ad-hoc 签名，尚未经过 Apple 公证**；如首次打开被系统拦截，对本 Release 下载并安装的应用执行：

  ```bash
  xattr -dr com.apple.quarantine /Applications/Unity.app
  ```

- 完整安装说明见 [README](https://github.com/Buaixihongshi/Unity#macos下载安装包)。本次提供 arm64 包，不包含 Intel 包。

## 从旧版升级

1. 先完成或停止正在进行的任务，退出旧版 Unity。
2. 备份 `~/Library/Application Support/Unity/`，再替换 `/Applications/Unity.app`。
3. 保留原数据目录，已有会话、产物和保存的设置继续使用；不要删除数据目录来升级。
4. 需要 Workflow 时，在「设置 → 扩展」开启任务，并在「Unity → 选择项目仓库…」选择 Git 仓库。

## 校验与源码

附件提供 SHA-256 校验文件。下载到同一目录后可运行：

```bash
shasum -a 256 -c Unity-1.0.0-arm64.dmg.sha256
```
