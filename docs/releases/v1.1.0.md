Unity v1.1.0：桌面体验与模型配置更新。

## 升级内容

相比 v1.0.0：

- **角色模型配置**：每个角色的主用和备用连接可分别选择推理强度，按 CLI / 模型能力校验（#131）。
- **桌面体验**：支持快捷键缩放页面和字体，新增轻量更新状态入口与设置页桌面配置；外壳与页面状态通过桌面桥同步（#121、#166、#167）。
- **更新组件**：集成 Sparkle 整包更新框架及活动任务保护（#178）。本次发行未配置正式更新签名公钥，自动更新和应用内检查更新保持禁用，请通过本 Release 手动下载安装。
- **运行稳定性**：修正动态续期未同步延长单轮预算、托管服务随终端关闭退出、事件与维护记录时区，以及开发环境空闲回收问题（#138、#124、#164、#174）。
- **打包与测试**：修正 Python 字节码泄露构建路径的问题，隔离后端测试与宿主的实例路径（#165、#157）。

## 下载与安装

`Unity-1.1.0-arm64.dmg` 适用于 Apple Silicon（M 系列），macOS 12 或更高版本。内置 Python 与前端，调用模型仍需安装并登录对应 CLI。

本包使用 **ad-hoc 签名，未经过 Apple 公证**。打开 DMG，将 Unity 拖入“应用程序”。若首次打开被系统拦截，对本 Release 下载并安装的应用执行：

```bash
xattr -dr com.apple.quarantine /Applications/Unity.app
```

## 从旧版升级

1. 完成或停止正在进行的任务，退出 Unity。
2. 备份 `~/Library/Application Support/Unity/`，再替换 `/Applications/Unity.app`。
3. 保留原数据目录，已有会话、产物与设置继续使用。
