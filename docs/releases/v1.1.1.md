Unity v1.1.1：启用签名校验的 macOS 应用内更新。

## 升级内容

- 内置 Unity 正式 Sparkle 更新公钥，启用更新检查及默认自动下载。
- 更新包使用 Ed25519 签名校验；下载完成后在正常退出时安装，也可在应用内选择立即重启。运行任务或活动状态未知时阻止立即重启。
- 后续版本通过 GitHub Release 分发，并由主线 appcast 发布版本、下载地址、签名及文件大小。

## 首次安装与升级

v1.1.0 及更早未配置公钥的版本不会自动发现本次更新，需要手动安装一次 v1.1.1。
完成或停止活动任务、退出 Unity，并备份 `~/Library/Application Support/Unity/` 后，打开 DMG 将 Unity 拖入“应用程序”。保留原数据目录，会话、设置和产物继续使用。

`Unity-1.1.1-arm64.dmg` 适用于 Apple Silicon（M 系列），macOS 12 或更高版本。调用模型仍需安装并登录相应 CLI。

本包使用 **ad-hoc 签名，未经过 Apple 公证**。Sparkle 更新签名不等于 Apple 公证。若首次安装被系统拦截，对本 Release 下载并安装的应用执行：

```bash
xattr -dr com.apple.quarantine /Applications/Unity.app
```

## 校验

```bash
shasum -a 256 -c Unity-1.1.1-arm64.dmg.sha256
```

附件包含 DMG、SHA-256 校验文件及 `.sparkle-signature.txt`（Sparkle 更新签名与字节数）。私钥保留在发布者本机钥匙串，不在仓库或附件中。完整源码见 `v1.1.1` 标签。
